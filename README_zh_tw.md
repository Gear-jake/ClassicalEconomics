# 古典經濟學 Classical Economics

> 為 WorldBox 引入完整的宏觀經濟模擬 —— 財富採集、經濟週期、王國貿易、社會動盪與智慧生物消費。

**作者**：Jake
**版本**：0.13.0
**類型**：宏觀經濟 / 模擬增強
**目標版本**：WorldBox 0.51.2+

---

## 模組簡介

「古典經濟學」讓你的世界真正擁有經濟。模組會識別所有**智慧生物**（包括外星人、龍等能建立文明的種族）的財富，並以此為基礎模擬一整套宏觀經濟運行：

- 每年自動採集所有開智種族的金幣與戰利品，計算**全球 GDP、人均財富、基尼係數、物價指數**
- 財富會驅動 **繁榮 → 衰退 → 蕭條 → 復甦** 的完整經濟週期
- 王國之間透過**貿易金流**重新分配財富（不憑空造幣），並按**生物群系經濟特長**形成比較優勢貿易
- 貧富差距會引發**動盪、叛亂、革命**，也會觸發國王**加稅、改革**
- 富裕的智慧生物每年大量消費：買武器、建投資、造軍械、繳稅、施捨窮人……
- 生物死亡時財富按 **父母 → 配偶 → 子嗣** 順序繼承，城市村長收取遺產稅
- **勞動分工**：職業人口每年靠勞動創造工資（生產函數）
- **銀行信貸**：富人放貸給窮人，蕭條期違約率飆升，危機沿貿易路線傳染
- **災害衝擊**：火山、隕石等災害蒸發受災城市財富，火山短期提振礦產
- 支援 **簡中 / 繁中 / English / Русский** 四語言介面一鍵切換

一切以**遊戲原版機制**為基礎，不引入任何外部資源，資料全程在背景執行緒計算。

## 核心功能

### 1. 宏觀經濟統計
- 採集**所有智慧種族**的財富（按種族智慧特質判定，外星人當國王也能統計）
- 全球總財富（GDP）、人均財富、文明人口
- **基尼係數**：0 = 完全均等，1 = 完全不均等
- **物價指數（CPI）**：隨貨幣流通速度與泡沫升溫而上漲，直觀呈現通膨
- 按王國拆分：各王國財富、人均、貧富差距、人口

### 2. 經濟週期
- 四階段週期：**繁榮 → 衰退 → 蕭條 → 復甦**，階段轉移由全球貧富差距驅動
- 繁榮期：信用擴張，按 GDP 比例注入金幣，泡沫持續累積
- 泡沫破裂：累積泡沫超過閾值，大量金幣蒸發，轉入衰退
- 蕭條期：人均財富跌破生存線 → 饑荒，貧困人口死亡
- 復甦期：緩慢回暖，重建信心
- 可在工具列手動切換經濟階段

### 3. 社會動盪與革命
- 自動檢測貧富差距大的王國，觸發原版叛亂
- **煽動動盪 / 鎮壓動亂**：選擇任意王國手動干預
- 叛亂持續過久 → 革命爆發：舊政權被推翻，王國人口按比例死亡
- 高基尼政權崩塌鏈：**街頭起義**（全城暴動 + 殺富濟貧 + 推翻國王）
- 戰爭掠奪：戰爭結束後勝方掠奪敗方金幣（v0.8.4 修復後真正生效）

### 4. 王國貿易金流
- 人均財富高於全球均值的王國為貿易**順差**（獲得金幣），低於者為**逆差**（支付金幣）
- 金幣經城市倉庫結算，與原版繳稅同管道
- 全王國順差總額 = 逆差總額，**總和為零，不憑空造幣**
- **自適應貿易參數**（v0.11）：距離衰減/運輸成本/套利權重由遊戲狀態每週期動態推導（地圖尺度/海路占比/船隊規模/平均運距/價格離散度），EMA 平滑，無固定配置
- **區域價格**：各王國按供需形成本地價格（產出高→價低，人口超載→價高），價差驅動套利貿易
- **貿易淨額排名**（v0.13）：獨立懸浮窗展示各城市/國家淨貿易額（總出口−總進口）排名，順差綠色逆差紅色，國家值 = 其所有城市貿易額之和
- **貿易軍力**（v0.13）：貿易順差國國民獲得傷害/護甲加成，逆差國國民遭受傷害懲罰（順差率 = 淨額÷GDP，閾值可配），貿易強國在戰爭中更佔優勢

### 5. 生物群系經濟特長
- 每個王國按領地特徵獲得一種**產出特長**（農業/狩獵/伐木/採礦/建造……），有對應的產出加成
- 特長王國為貿易**出口**方，非特長王國為**進口**方，驅動**比較優勢貿易**
- 特產加成與王國實際領地動態匹配，形成天然的分工格局

### 6. 勞動分工（生產函數）
- 讀取原生 `citizen_job` 職業，按職業掛鉤財富生產率
- 職業人口每年靠勞動創造「工資」（勞動創造財富），無業人口生產率低、不創造工資
- 職業 → 代碼映射與生產率表均為純資料，由背景執行緒聚合每王國勞動統計

### 7. 智慧生物消費系統
富人不再囤積金幣——每年按財富比例消費，**七種消費方式**輪換：

| 消費方式 | 說明 |
|---------|------|
| 購買武器 | 富人為自己購置真實武器 |
| 建造投資 | 投資建造防禦塔樓 |
| 製造軍械 | 大量製造裝備和武器 |
| 武器批發 | 整批採購武器 |
| 時代事件 | 花費金幣觸發時代事件 |
| 慈善施捨 | 金幣轉移給同城最窮的智慧生物 |
| 繳納稅收 | 金幣繳納給城市倉庫 |

金幣**不會憑空消失**——全部真實流向城市領袖、窮人或國家財政。

### 8. 王國時代事件
- **盛世**：國民幸福 +30、生育 +10
- **復興**：國民幸福 +35、傷害 +10、生育 +10
- **強盛期**：國民幸福 +20、傷害 +5、護甲 +5
- **經濟崩潰**：蕭條期 + 人均財富大幅下滑觸發，國民幸福 -15、傷害 +30、護甲 +20，並伴隨人口流失

### 9. 銀行信貸與危機傳染
- 富人（財富 > 2×人均）自動放貸給同城窮人，按年利率計息
- 蕭條期**違約率飆升**，違約直接造成放貸人（富人）財富損失
- 違約率越過閾值觸發**銀行危機**，沿貿易路線傳染逆差貿易夥伴（危機傳染）
- 統計級模擬（不儲存個債紀錄），零記憶體膨脹

### 10. 災害經濟衝擊
- 檢測三類災害訊號：王國人口驟降 >30%、城市數驟降 >25%、城市 tile 為災害類型（火山/隕石坑）
- 受災城市倉庫財富按比例**蒸發**（財富真實消失）
- 火山短期提振礦產：繁榮期受災區域產出獲得額外加成
- 效果檢測 + tile 反射檢測，無需 hook 原版災害事件，相容所有災害類型

### 11. 遺產繼承
- 智慧生物死亡時，金幣按 **父母 → 配偶 → 子嗣** 順序轉移
- 城市（村長）收取遺產稅
- 無任何繼承者時，全部財產歸村長所有

### 12. 政策與治理
- 高基尼係數的王國會嘗試推行**貧富調節政策**
- 政策失敗則統治者退位（甚至死亡）——經濟治理失敗是要付出代價的

### 13. 人口與勞動力
- 人口壓力：王國人口 vs 承載力
- 勞動生產率：按職業統計產出

## 介面功能

底部工具列新增**經濟 Tab**（金幣圖示），包含 7 個按鈕（滑鼠懸停可查看提示）：

| 按鈕 | 功能 |
|------|------|
| 經濟概覽 | 開啟/關閉經濟主面板（可拖拽、可縮放、不暫停遊戲） |
| 干預王國 | 選擇王國進行煽動或鎮壓 |
| 立即採集 | 手動執行一次資料採集與經濟重算 |
| 清除歷史 | 清空所有歷史快照資料 |
| 全球富豪榜 | 查看財富排行 |
| 經濟事件 | 開啟/關閉事件流懸浮窗 |
| 切換階段 | 循環切換經濟階段（繁榮→衰退→蕭條→復甦） |

**經濟概覽面板**包含：
- 概覽頁：GDP、人均、人口、貧富差距、王國排名
- 趨勢頁：**財富趨勢圖**（全球財富 + 動態 Top5 王國折線 + 階段色帶 + 豎行圖例 + 宏觀指標摘要）+ **貧富差距趨勢圖**
- 社會震盪狀態、歷史快照

**趨勢圖特性**（v0.7.0 重製）：
- **動態國家折線**：國家進榜後折線出現、跌出排名後折線斷裂消失、再入榜自動續線
- **階段色帶背景**：綠繁榮 / 橙衰退 / 紅蕭條 / 藍復甦，一目瞭然的經濟週期軌跡
- **宏觀指標摘要**：總產出、物價指數、文明人口、人均財富、貧富差距一行概覽
- **豎行圖例**：逐行顯示國家色塊、名稱與最新值；跌出榜的國家以灰色標註「已跌出」

**經濟事件視窗**（v0.8.3 雙環改造）：
- **重大事件**（革命/起義/泡沫破裂/天災/銀行危機/時代/經濟崩潰/改革失敗/王位更迭/戰爭掠奪）史書級緩衝，不被高頻事件擠出
- **普通事件**（建造投資/軍械製造/武器批發等消費事件）獨立環形緩衝
- 視窗頂部類型統計行：只顯示本局實際發生過的類型，一目瞭然

支援 **簡中 / 繁中 / English / Русский** 四語言介面一鍵切換（隨遊戲語言自動切換，也可在設定中固定介面語言）。

## 安裝方法

手動安裝：
1. 將 `EconomyMod` 資料夾放入 `WorldBox/Mods/` 目錄
2. 確認目錄結構為：
   ```
   WorldBox/
   └── Mods/
       └── EconomyMod/
           ├── EconomyMod.dll
           ├── mod.json
           ├── icon.png
           └── Locales/
               ├── ch.json
               ├── zh_tw.json
               ├── en.json
               └── ru.json
   ```
3. 啟動遊戲，在模組清單中啟用「古典經濟學」

### 依賴
- 需要安裝 **NeoModLoader (NML)** 模組載入器
- 建議使用最新版 WorldBox（0.51.2+）

## 相容性

- 與原版遊戲機制深度整合，不修改遊戲核心檔案
- 時代特質透過遊戲原生特質系統註冊，可正常顯示圖示與描述
- 支援讀檔、新地圖（自動重置/保留狀態邏輯完善）
- 所有統計在背景執行緒計算，主執行緒零開銷
- **與 Optime 優化模組相容**：Optime 的 `ActorJobFlatten` 扁平化重寫未做空引用防禦、在生物大規模死亡（饑荒/殺富/戰爭掠奪等）後遍歷到已回收槽位導致 NRE 崩潰。本模組的 `OptimeCompatibility` 相容層**完全不修改 Optime 任何檔案**，透過 Harmony Transpiler 在執行時向 Optime 已編譯的扁平迴圈注入 null 防禦（actor 為 null 時跳過本次迭代，優化邏輯 100% 保留），並以 Finalizer 兜底殘餘 NRE——正常路徑零開銷，安裝 Optime 時二者可安全共存

## 常見問題

**Q：經濟會一直卡在復甦嗎？**
不會。可以點擊工具列的「切換階段」按鈕循環手動切換階段（繁榮→衰退→蕭條→復甦）。

**Q：會影響遊戲效能嗎？**
不會。統計計算全部在背景執行緒完成，主執行緒只做採集與顯示。
