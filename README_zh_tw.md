# 古典經濟學 Classical Economics

> WorldBox 宏觀經濟 + 國家治理模擬模組 ｜ 目前版本 *1.4.1* ｜ 需要 NeoModLoader (NML)

## 功能總覽

**宏觀經濟**
- 全種族（含惡魔/外星人）財富採集：GDP / 人均 / 基尼係數 / CPI，按王國拆分
- 經濟週期：繁榮 → 衰退 → 蕭條 → 復甦，泡沫破裂、飢荒、通膨
- 勞動工資、銀行信貸與違約傳染、災害衝擊、遺產繼承與傷害分配
- 社會動盪：叛亂 → 起義 → 革命；戰爭掠奪與王位繼承監測

**玩家扮演 · 中央銀行家**
- 大地圖懸停國家按 **G**（可改鍵）：認領國家 / 打開內閣
- 王室金庫：認領撥款 + 每期稅負；政策/法令/建築/外交全部真實扣費
- 6 個持續政策 × 三檔槽位制、一次性法令、**原版建築放置**（10 種，點擊地圖建造）
- 政績記錄 + 本國 GDP 趨勢圖（近 40 期）
- 外交：宣戰/求和/結盟/贈禮/協定——兩級頁面（列表 → 詳情：三層旗章 + 國家數據）

**國法體系 · 法典**
- **全王國法律 28 條 × 5 檔 + 國策 16 條 × 3 檔**，AI 各國每年按國情自動演變（+ 6 種國性）
- 互斥法組合、升檔付費降檔免費；效果真實掛接 10 個引擎
- 法典加成落到**國民特質**；法典寫入存檔；即時聚合效果總覽與檔位語義名

**效能與品質**
- 年度結算分幀（4ms/幀，稅收永不削減）、自動記憶體清理
- 46 項自動化門禁 + 效能稽核；金幣轉移守恆
- 四語言介面（简体 / 繁體 / English / Русский）；石板金邊 9-slice UI

## 安裝

1. 安裝 [NeoModLoader](https://github.com/neoModLoader) (NML)
2. 將 `EconomyMod` 資料夾放入 `WorldBox/Mods/`
3. 遊戲內模組列表啟用「古典經濟學」

## 操作提示

- **G**（可改鍵）：懸停國家 → 認領 / 開啟內閣（或國家視窗右上角帳本按鈕）
- 內閣 5 頁：財稅 / 政策 / 法令·建設 / 外交 / 法典
