# Классическая экономика

> Мод макроэкономики и государственного управления для WorldBox ｜ Версия *1.4.0* ｜ Требуется NeoModLoader (NML)

## Обзор функций

**Макроэкономика**
- Богатство всех рас (демоны, пришельцы...): ВВП, среднее богатство, Джини, CPI по королевствам
- Деловой цикл: Бум → Спад → Депрессия → Восстановление; крах пузырей, голод, инфляция
- Зарплаты, банковский кредит и заражение дефолтами, шоки катастроф, наследование с распределением по урону
- Волнения: мятеж → восстание → революция; разграбление войн и смена династий

**Играбельное правительство · Центральный банкир**
- Наведите курсор на королевство и нажмите **G** (переназначается): принять / открыть Кабинет
- Королевская казна: стартовый грант + периодические налоги; политики, указы, стройка и дипломатия тратят золото
- 6 постоянных политик × 3 уровня, разовые указы, **размещение ванильных зданий** (10 видов, клик по карте)
- Журнал правления + график ВВП (40 циклов); дипломатия в два уровня (список → детали: трёхслойный герб)

**Национальный свод законов (кодекс)**
- **Каждое королевство: 28 законов × 5 уровней + 16 политик × 3 уровня**; AI эволюционирует ежегодно (+ 6 характеров)
- Взаимоисключающие пары, платные повышения; эффекты подключены к 10 движкам
- Бонусы видны на **чертах граждан**; кодекс сохраняется; сводка эффектов и семантические названия уровней

**Производительность и качество**
- Годовой расчёт по кадровому бюджету (4 мс/кадр; налоги не сокращаются); автоочистка памяти
- 46 автоматических гейтов; золото консервативно
- Четырёхязычный интерфейс; UI из сланца и золота (9-slice)

## Установка

1. Установите [NeoModLoader](https://github.com/neoModLoader) (NML)
2. Поместите `EconomyMod` в `WorldBox/Mods/`
3. Включите мод в списке

## Управление

- **G** (переназначается): навести на королевство → принять / открыть Кабинет
- Вкладки: Финансы / Политики / Указы и стройка / Дипломатия / Кодекс
