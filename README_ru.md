# Классическая экономика (Classical Economics)

> Полная макроэкономическая симуляция для WorldBox — отслеживание богатства, экономические циклы, торговля между королевствами, социальные волнения и расходы разумных существ.

**Автор**: Jake
**Версия**: 0.5.0
**Тип**: Экономика / Симуляция
**Целевая версия**: WorldBox 719+

---

## О моде

«Классическая экономика» дарит вашему миру настоящую экономику. Мод определяет всех **разумных существ** (включая инопланетян, драконов и любые расы, способные строить цивилизацию), отслеживает их богатство и симулирует полноценную макроэкономическую систему:

- Каждый год собирает монеты и добычу всех цивилизованных существ, вычисляя **мировой ВВП, средний достаток и коэффициент Джини**
- Богатство управляет полным экономическим циклом: **Подъём → Спад → Депрессия → Восстановление**
- Королевства перераспределяют богатство через **торговые потоки** (монеты не создаются из ниоткуда)
- Неравенство вызывает **волнения, восстания и революции** — и заставляет королей **вводить налоги и реформы**
- Богатые разумные существа ежегодно тратят: покупают оружие, финансируют стройки, создают арсеналы, платят налоги, жертвуют бедным…
- Когда разумное существо умирает, его богатство наследуется **родители → супруг(а) → дети**, а мэры городов собирают налог на наследство

Всё основано на **механиках ванильной игры** — никаких внешних ресурсов, вся статистика вычисляется в фоновом потоке без влияния на производительность.

## Основные возможности

### 1. Макроэкономическая статистика
- Учитывает **все разумные расы** (определяются по признаку разумности — правители-инопланетяне тоже учитываются)
- Мировой ВВП, средний достаток, цивилизованное население
- **Коэффициент Джини**: 0 = полное равенство, 1 = полное неравенство
- Разбивка по королевствам: богатство, средний достаток, неравенство, население

### 2. Экономический цикл
- Цикл из четырёх фаз: **Подъём → Спад → Депрессия → Восстановление**, управляется мировым разрывом богатства
- Подъём: кредитная экспансия — вливание монет как доля ВВП, накопление пузыря
- Разрыв пузыря: когда накопленное значение превышает порог, монеты испаряются, наступает спад
- Депрессия: когда средний достаток падает ниже черты выживания → голод, гибель бедняков
- Восстановление: медленное оживление, восстановление доверия
- Фазы можно переключать вручную с панели инструментов

### 3. Социальные волнения и революции
- Автоматически обнаруживает королевства с высоким неравенством и запускает ванильное восстание
- **Разжигание волнений / Подавление волнений**: ручное вмешательство в любом королевстве
- Затяжное восстание → **революция**: старый режим падает, часть населения гибнет
- Военная добыча: победители захватывают долю монет проигравшего королевства

### 4. Торговые потоки королевств
- Королевства выше среднего мирового достатка имеют торговый **профицит** (получают монеты); ниже — **дефицит** (платят монеты)
- Расчёт через городские казны по каналу ванильных налогов
- Общий профицит = общий дефицит — **нулевая сумма, монеты не создаются из ничего**

### 5. Система расходов разумных существ
Богачи больше не копят монеты — они ежегодно тратят часть богатства через **семь способов**:

| Способ | Описание |
|--------|----------|
| Покупка оружия | Приобретение настоящего оружия |
| Инвестиции в стройку | Финансирование строительства башен |
| Создание арсенала | Массовое производство снаряжения и оружия |
| Оптовая закупка оружия | Крупная партия оружия |
| Эпохальное событие | Трата монет для запуска эпохальных событий |
| Благотворительность | Передача монет беднейшему разумному существу в том же городе |
| Уплата налогов | Взнос монет в городскую казну |

Монеты **не исчезают** — они реально уходят лидерам городов, бедным или государству.

### 6. Эпохальные события королевств
- **Золотой век**: счастье +30, рождаемость +10
- **Возрождение**: счастье +35, урон +10, рождаемость +10
- **Расцвет**: счастье +20, урон +5, броня +5
- **Экономический коллапс**: запускается при депрессии и резком падении достатка — счастье −15, урон +30, броня +20, плюс миграционный отток

### 7. Наследование
- При смерти богатство переходит **родители → супруг(а) → дети**
- Город (мэр) собирает налог на наследство
- Если наследников нет — всё достаётся мэру

### 8. Политика и управление
- Королевства с высоким коэффициентом Джини пытаются проводить **политику перераспределения богатства**
- Провал политики может свергнуть (или убить) правителя — плохое управление экономикой имеет последствия

### 9. Население и труд
- Демографическое давление: население королевства против ёмкости
- Производительность труда: выпуск по профессиям

## Интерфейс

Новая вкладка **Экономика** (иконка монеты) на нижней панели инструментов с 11 кнопками (при наведении — подсказки):

| Кнопка | Функция |
|--------|----------|
| Обзор экономики | Открыть/закрыть главную перетаскиваемую и масштабируемую панель (игра не ставится на паузу) |
| Разжечь волнения | Выбрать королевство для восстания |
| Подавить волнения | Выбрать королевство для подавления восстания |
| Собрать сейчас | Запустить сбор данных и пересчёт вручную |
| Очистить историю | Стереть все исторические снимки |
| Список богачей | Просмотр самых богатых существ |
| Экономические события | Вкл/выкл окно потока событий |
| Подъём / Спад / Депрессия / Восстановление | Ручное переключение экономической фазы |

**Панель обзора** включает:
- Страница обзора: ВВП, средний достаток, население, разрыв богатства, рейтинг королевств
- Страница трендов: **график богатства** + **график коэффициента Джини** (цветные полосы фона показывают фазу: зелёный подъём / оранжевый спад / красная депрессия / синее восстановление; красная и зелёная линии — пороги опасности и здоровья)
- Статус волнений и исторические снимки

Поддерживается переключение интерфейса **китайский/английский**.

## Настройки

Все параметры настраиваются через меню настроек NML, включая:
- Вкл/выкл обнаружения волнений, порог срабатывания, льготный период, максимум городов за бунт
- Вкл/выкл цикла, линии опасности/здоровья разрыва богатства, число периодов пересечения порога
- Коэффициент стимулирования подъёма, фактор пузыря, порог пузыря, макс. длительность подъёма
- Черта выживания, смертность от голода
- Доля военной добычи, задержка революции, доля погибших при революции
- Вкл/выкл обновления в реальном времени и интервал
- Вывод в мировой журнал

## Частые вопросы

**В: Почему мой инопланетный правитель не в статистике экономики?**
Мод определяет цивилизованные виды по признаку разумности — учитываются любые расы, способные строить города-государства.

**В: Экономика застряла в восстановлении?**
Нет. Фазы можно переключать вручную кнопками на панели инструментов.

**В: Влияет ли мод на производительность?**
Нет. Все расчёты выполняются в фоновом потоке; основной поток только собирает и отображает данные.
