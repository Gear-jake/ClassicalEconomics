# Классическая экономика

> Полная макроэкономическая симуляция для WorldBox — отслеживание богатства, экономические циклы, торговля королевств, социальные волнения и расходы разумных существ.

**Автор**: Jake
**Версия**: 0.13.0
**Тип**: Макроэкономика / Улучшение симуляции
**Целевая версия**: WorldBox 0.51.2+

---

## Обзор

«Классическая экономика» даёт вашему миру настоящую экономику. Мод отслеживает богатство всех **разумных существ** (включая инопланетян, драконов и любые расы, способные строить цивилизацию) и симулирует на его основе целую макроэкономическую систему:

- Каждый год собирает монеты и добычу всех разумных рас, вычисляя **мировой ВВП, средний достаток, коэффициент Джини и индекс цен (ИПЦ)**
- Богатство управляет полным циклом **Подъём → Спад → Депрессия → Восстановление**
- Королевства перераспределяют богатство через **торговые потоки** (монеты не создаются из ничего), а **биомные специализации** создают торговлю на сравнительных преимуществах
- Неравенство провоцирует **волнения, восстания и революции**, а также заставляет королей **повышать налоги или проводить реформы**
- Богатые ежегодно много тратят: покупают оружие, инвестируют в стройку, создают арсеналы, платят налоги, раздают милостыню…
- При смерти богатство наследуется **родители → супруг(а) → дети**, мэр города собирает налог на наследство
- **Разделение труда**: занятое население создаёт зарплаты трудом (производственная функция)
- **Банковский кредит**: богатые дают в долг бедным; в депрессии уровень дефолтов растёт, кризисы распространяются по торговым путям
- **Катастрофы**: вулканы и метеориты испаряют богатство пострадавших городов; вулканы временно усиливают добычу
- **Интерфейс на 4 языках**: 简体中文 / 繁體中文 / English / Русский

Всё построено на **ванильных механиках игры** — никаких внешних ресурсов, все вычисления идут в фоновом потоке.

## Возможности

### 1. Макростатистика
- Отслеживание всех разумных существ (по черте разума; короли-инопланетяне тоже учитываются)
- Мировой ВВП, средний достаток, цивилизованное население, коэффициент Джини
- **Индекс цен (ИПЦ)**: растёт вместе со скоростью обращения денег и накоплением пузыря — видимая инфляция
- Разбивка по королевствам: богатство, среднее, неравенство, население

### 2. Экономический цикл
- Четыре фазы: **Подъём → Спад → Депрессия → Восстановление**, управляется мировым разрывом богатства
- Подъём: кредитная экспансия, вливание монет по доле ВВП, пузырь продолжает расти
- Разрыв пузыря: когда накопленный пузырь превышает порог, большое количество монет испаряется
- Депрессия: средний достаток ниже черты выживания → голод и смерти
- Восстановление: медленный подъём и восстановление доверия
- Ручной перебор фаз с панели инструментов

### 3. Волнения и революции
- Автообнаружение королевств с высоким неравенством и запуск ванильного восстания
- **Разжигание / подавление** волнений в любом королевстве вручную
- Затяжное восстание → **революция**: старый режим свергнут, часть населения погибает
- Цепочка краха режима с высоким Джини: **уличное восстание** (бунт всего города, «грабь богатых — корми бедных», свержение короля)
- **Военный грабёж**: победители забирают монеты побеждённых (по-настоящему работает с v0.8.4)

### 4. Торговые потоки королевств
- Королевства выше среднего мирового достатка — торговый **профицит** (получают монеты), ниже — **дефицит** (платят монеты)
- Расчёт через городскую казну, тот же канал, что и ванильные налоги
- Общий профицит = общий дефицит, **нулевая сумма, монеты не создаются из ничего**
- **Адаптивные параметры торговли** (v0.11): затухание по расстоянию / транспортные расходы / вес арбитража выводятся каждый цикл из состояния игры (масштаб карты / доля морских путей / флот / средняя дальность / дисперсия цен), сглаживание EMA, без фиксированных настроек
- **Региональные цены**: каждое королевство формирует локальную цену из спроса и предложения (высокое производство → низкая цена, перенаселение → высокая цена); разница цен ведёт арбитражную торговлю
- **Рейтинг чистого торгового баланса** (v0.13): отдельное окно ранжирует города/страны по чистому балансу (экспорт − импорт), профицит зелёным / дефицит красным; баланс страны = сумма её городов
- **Торговая военная мощь** (v0.13): профицитные страны получают бонус к урону/броне, дефицитные — штраф (ставка = баланс ÷ ВВП, пороги настраиваются) — торговые державы сильнее в войне

### 5. Биомные экономические специализации
- Каждое королевство получает **специализацию по территории** (земледелие/охота/лес/шахты/строительство…) с бонусами к производству
- Королевства-специалисты — **экспортёры** в торговле, остальные — **импортёры**; так возникает **торговля на сравнительных преимуществах**
- Бонусы динамически соответствуют реальной территории королевства, создавая естественное разделение труда

### 6. Разделение труда (производственная функция)
- Читает ванильную профессию `citizen_job` и связывает продуктивность с профессией
- Занятое население ежегодно зарабатывает «зарплату» трудом (труд создаёт богатство); безработные не создают зарплаты
- Карта профессия → код и таблица продуктивности — чистые данные, агрегируются в фоновом потоке

### 7. Расходы разумных существ (7 способов)
Богатые ежегодно тратят монеты вместо накопления:

| Способ | Описание |
|--------|----------|
| Покупка оружия | Покупка настоящего оружия для себя |
| Инвестиции в стройку | Строительство оборонительных башен |
| Создание арсенала | Массовое производство снаряжения и оружия |
| Оптовая закупка оружия | Покупка оружия партиями |
| Эпохальное событие | Трата монет на запуск эпохального события |
| Благотворительность | Передача монет беднейшему существу города |
| Налоги | Уплата монет в городскую казну |

Монеты **не исчезают** — они реально уходят лидерам городов, бедным или государству.

### 8. Эпохальные события королевств
- **Золотой век**: счастье +30, рождаемость +10
- **Возрождение**: счастье +35, урон +10, рождаемость +10
- **Расцвет**: счастье +20, урон +5, броня +5
- **Экономический коллапс**: запускается депрессией + резким падением среднего достатка; счастье -15, урон +30, броня +20, плюс отток населения

### 9. Банковский кредит и кризисное заражение
- Богатые (достаток > 2× среднего) автоматически дают в долг бедным гражданам своего города под годовой процент
- Уровень дефолтов резко растёт в депрессии, напрямую обедняя богатых кредиторов
- Выше порога заражения разражается **банковский кризис**, распространяющийся по торговым путям на дефицитных партнёров
- Статистическая симуляция (без записей по отдельным долгам), нулевой рост памяти

### 10. Катастрофы как экономический шок
- Три сигнала: падение населения королевства >30%, падение числа городов >25%, тайл города — катастрофа (вулкан/метеорит)
- Богатство казны пострадавших городов **испаряется** на долю
- Вулканы временно усиливают добычу: бонус к производству в пострадавших регионах во время подъёма
- Обнаружение через эффекты и отражение тайлов — без хуков ванильных событий, совместимо со всеми катастрофами

### 11. Наследование
- При смерти монеты переходят **родители → супруг(а) → дети** по порядку
- Мэр города собирает налог на наследство
- Если наследников нет вовсе — всё имущество достаётся мэру

### 12. Политика и управление
- Королевства с высоким Джини пытаются проводить **политику перераспределения богатства**
- Провал политики свергает (или даже убивает) правителя — неудачное управление экономикой имеет цену

### 13. Население и труд
- Демографическое давление: население королевства vs вместимость
- Производительность труда: выпуск по профессиям

## Интерфейс

На нижней панели появляется новая **вкладка «Экономика»** (иконка монеты) с 7 кнопками (наведите курсор для подсказки):

| Кнопка | Функция |
|--------|---------|
| Экономика | Переключение главной панели экономики (перетаскивается, масштабируется, игра не ставится на паузу) |
| Вмешательство | Выбрать королевство для разжигания или подавления |
| Собрать | Ручной сбор данных и пересчёт экономики |
| Очистить | Стереть все исторические данные |
| Богатейшие | Просмотр самых богатых |
| События | Переключение окна потока событий |
| Сменить фазу | Цикл фаз: Подъём→Спад→Депрессия→Восстановление |

**Панель обзора** содержит:
- Вкладку «Обзор»: ВВП, средний достаток, население, разрыв богатства, рейтинг королевств
- Вкладку «Тренды»: **график богатства** (мировое богатство + динамические линии Топ-5 королевств + цветовые полосы фаз + вертикальная легенда + сводка макропоказателей) + **график тренда Джини**
- Состояние социальных волнений, исторические снимки

**Особенности графика трендов** (переработан в v0.7.0):
- **Динамические линии королевств**: линия появляется при входе в рейтинг, рвётся при выпадении и продолжается при повторном входе
- **Цветовые полосы фаз** за графиками: зелёный подъём / оранжевый спад / красный депрессия / синий восстановление
- **Сводка макропоказателей**: выпуск, индекс цен, население, средний достаток, разрыв богатства
- **Вертикальная легенда**: цвет + название + последнее значение для каждого королевства; выбывшие показаны серым «выбыло»

**Окно событий** (двойные кольцевые буферы с v0.8.3):
- **Важные события** (революция/восстание/разрыв пузыря/катастрофа/банковский кризис/эпоха/коллапс/провал реформ/смена трона/военный грабёж) хранятся в буфере эпического масштаба — их не вытесняют частые события
- **Обычные события** (инвестиции в стройку / создание арсенала / оптовая закупка и т.д.) — в собственном кольцевом буфере
- Строка статистики типов вверху: показываются только типы, реально случившиеся в этой партии

Интерфейс на 4 языках: 简体中文 / 繁體中文 / English / Русский (следует за языком игры или фиксируется в настройках).

## Настройки

Все параметры настраиваются через окно настроек мода NML, включая:
- **Язык интерфейса**: ui_language (zh / zh_tw / en / ru, независимо от языка игры)
- Переключатель волнений, порог срабатывания, стартовый льготный период, число городов на бунт
- Переключатель цикла, опасная/здоровая линии разрыва богатства, число периодов вне линии
- Доля стимулирования подъёма, коэффициент накопления пузыря, порог разрыва пузыря, максимум длительности подъёма
- Черта выживания, смертность от голода
- Доля военного грабежа, доля расточительства, задержка революции, доля казнённых при революции
- Порог уличного восстания, задержка восстания, доля казнённых богачей, доля перераспределения «грабь богатых»
- Переключатель налога на богатство, ставка, линия освобождения
- Переключатель торговли, доля торгового потока
- Переключатель разделения труда, базовая зарплата
- Переключатель эпохальных событий, длительность, доля коллапса
- Переключатель и интервал обновления данных в реальном времени
- Переключатель банковского кредита, годовой процент, доля дефолтов в депрессии, порог заражения
- Переключатель катастроф, доля испарения богатства, бонус вулканов к добыче
- Скорость обращения денег, инфляционный бонус в период пузыря
- Переключатель вывода в мировой журнал

## Установка

Ручная установка:
1. Поместите папку `EconomyMod` в `WorldBox/Mods/`
2. Убедитесь, что структура такая:
   ```
   WorldBox/
   └── Mods/
       └── EconomyMod/
           ├── EconomyMod.dll
           ├── mod.json
           ├── icon.png
           └── Locales/
               ├── ch.json
               ├── zh_tw.json
               ├── en.json
               └── ru.json
   ```
3. Запустите игру и включите «Классическая экономика» в списке модов

### Зависимости
- Требуется **NeoModLoader (NML)**
- Рекомендуется последняя версия WorldBox (0.51.2+)

## Совместимость

- Основано на ванильных механиках игры, основные файлы не изменяются
- Эпохальные черты регистрируются через нативную систему черт (значки и описания работают)
- Поддержка загрузки сохранений и новых карт (логика сброса/сохранения отработана)
- Вся статистика вычисляется в фоновом потоке, без влияния на производительность
- **Совместимо с модом-оптимизатором Optime**: переписанный `ActorJobFlatten` Optime не защищён от пустых ссылок и роняет NRE при обходе переработанных слотов после массовой гибели (голод, казнь богачей, военный грабёж). Наш слой `OptimeCompatibility` **не изменяет ни одного файла Optime** — Harmony Transpiler внедряет защиту от null в уже скомпилированный плоский цикл Optime в рантайме (actor = null → пропустить итерацию, 100% оптимизации сохранено), а Finalizer подстраховывает остаточные NRE. Ноль накладных расходов на обычном пути — оба мода безопасно сосуществуют

## История версий

### v0.13.0 (2026-08-14)
**Рейтинг чистого торгового баланса + торговая военная мощь**.
- **Рейтинг чистого баланса**: окно переработано из графика долей в две таблицы чистого баланса (города / страны), каждая строка — экспорт / импорт / баланс (экспорт − импорт), баланс по убыванию, профицит зелёным / дефицит красным. Баланс страны = сумма торговли её городов, естественно согласовано.
- **Торговая военная мощь**: торговля теперь влияет на бой — профицитные страны (баланс ÷ ВВП ≥ порог) дают народу реальный бонус урона/брони (+20 урона / +10 брони), дефицитные — −20 урона. Настраиваемый переключатель + пороги (4 языка); перебор граждан только при смене уровня, иначе O(1).
- **Разрешена торговля между городами одной страны**: торговля больше не только между странами; пары городов одной страны тоже строят сухопутные рёбра и расчёты, учитываются в балансе города (взаимно гасятся на уровне страны).

### v0.12.0 (2026-08-14)
**Таблицы торговых пар (позже переработаны в рейтинг баланса в v0.13)**.
- График долей заменён таблицами город↔город / страна↔страна, города показывают настоящие имена (сбор на главном потоке через `SafeCityName`).
- Исправления: график тренда «зависал» после 50 лет (неверный старт чтения кольцевого буфера `HistoryService.GetRecent` → `start=_head-take`, Capacity 100→50); дрейф перетаскивания окна (anchor/pivot к соглашению `(0,0.5)`).

### v0.9.0 (2026-08-13)
**Улучшение географической торговли**: торговля из «абстрактного потока без пространственного измерения» превращается в настоящую географическую экономику.
- **Затухание по расстоянию**: фоновый поток определяет координаты тайла столицы каждого королевства (динамический поиск по нескольким именам полей + кэш, нулевые затраты производительности); объём торговли затухает по формуле `1/(1+среднее расстояние×коэффициент)` — далёкие королевства торгуют меньше, экономика становится локальнее; королевства без координат получают коэффициент 1 (без штрафа)
- **Транспортные расходы**: постоянное трение торговли съедает долю всего объёма; чем тяжелее логистика, тем меньше общая торговля
- **Региональные цены и арбитраж**: каждое королевство формирует региональный индекс цен из местного спроса и предложения (высокое производство → избыток → низкая цена; перенаселение → спрос → высокая цена); королевства с ценой ниже средней получают экспортный профицит, выше — импортный дефицит; вес разницы цен ведёт арбитражные потоки
- **Добавлено на панель**: карточка «Дисперсия цен» (коэффициент вариации региональных цен, 0 = везде одинаковые цены), колонка «Локальная цена» в рейтинге королевств (≥1,3× базовая янтарная инфляция / ≤0,8× дешёвый информационно-синий)

## Частые вопросы

**В: Экономика застрянет в восстановлении навсегда?**
Нет. Нажмите кнопку «Сменить фазу» на панели, чтобы вручную перебрать фазы (Подъём → Спад → Депрессия → Восстановление).

**В: Это повлияет на производительность игры?**
Нет. Вся статистика вычисляется в фоновом потоке; главный поток только собирает и отображает данные.
