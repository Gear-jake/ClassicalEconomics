【古典经济学 ClassicalEconomics v2.0.0】WorldBox 宏观经济 + 国家治理模拟模组

给 WorldBox 装上真实的经济系统：每个文明种族都有钱，算出 GDP、人均、基尼、CPI；繁荣→衰退→萧条→复苏四个阶段轮转，泡沫会破、饥荒会来、通胀会吃空你的金库。你可以认领一个国家当中央银行家，也可以只看 AI 各国自己治国、打仗、崩溃、复兴。

■ 三大玩法
1）开银行玩真货币：城市银行有真实账本，存款、放贷、收本息、坏账核销全程金币守恒；央行操作台调利率/额度/准备金，能调出通胀、挤兑和泡沫。
2）法典：28 部法律×5 档 + 16 项国策×3 档，AI 国家每年按国情和国性自己变法（尚武/重商/仁政/法理/闭关/科技），效果真实生效，升档花钱降档免费。
3）330 个抉择事件：财政/天灾/宫廷/军事/民生/外交六族，弹窗拍板。每局按世界种子随机启用约 68% 事件（这局蝗灾那局洪水），族倾向轮换（天灾之局/宫廷之局/战乱之局），跨年连锁剧情，选项还能宣战、结盟、迁都、升级建筑、让富豪暴富或破产、甚至触发世界大战（概率极小，全世界打你一个）。

■ 安装
1. 装 NeoModLoader（NML）；
2. 把 EconomyMod 文件夹放进 WorldBox/Mods/；
3. 进游戏 → 模组菜单 → 启用「古典经济学」。旧存档直接读。

■ 操作
悬停国家按 G 认领/开内阁（可改键）；国家窗口右上角账本按钮（可拖动）；内阁五页：财税/政策/法令建设/外交/法典；建设页选房屋、大厅、风车等 11 种原版建筑点地图放置。

■ 下载
GitHub 搜 Gear-jake/ClassicalEconomics：
1. 仓库页 Code → Download ZIP（解压后整个文件夹直接放进 Mods/ 即玩，自带编译好的 DLL）；
2. 或 Release 页下 ClassicalEconomics-2.0.0.zip（含源码的完整包）。
