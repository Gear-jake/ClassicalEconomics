# v0.90 发布说明（2026-08-27）

## 文明生物识别

- 全球经济概览不再只依赖种族的 `asset.civ` 标记判断文明生物。
- Actor 只要已经建城，或已经建国/属于王国，就会纳入文明财富、GDP、基尼系数和全球富豪榜统计。
- 火焰恶魔、冰霜恶魔等可建立文明但未被传统 `civ` 标记覆盖的种族，现在可以正常出现在经济概览中。
- 尚未建城且不属于任何王国的野生生物仍不会被纳入文明经济统计。
- 经济概览、富豪榜、税收、继承、银行、人口和贸易相关扫描统一使用该资格口径。

## 兼容与验证

- 文明资格判断集中在 `GameHelpers.IsCivilizedActor`，主要经济系统共用同一口径。
- 保留原有后台统计、历史缓存、贸易边界和资金守恒逻辑。
- Roslyn 生产编译、文明资格门禁及既有性能/稳定性门禁通过。
