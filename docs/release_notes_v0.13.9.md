# v0.13.9 发布说明（2026-08-20）

## 性能优化

- 继承与伤害共享扫描不再同时维护两份相同的存活单位 ID 索引，人口级哈希写入减半。
- 保留精确死亡检测与继承顺序，不使用近似统计替代经济计算。
- 贸易城市最近对搜索改为精确的距离下界剪枝，避免固定窗口漏掉真实最近路线。
- 消费城市冷却改为每周期统一淘汰，避免已消失城市条目长期滞留。
- 保留每位富裕生物的武器消费机会，以及军械 3–5 件、批发 6–10 件的既有结果；仅保留建筑投资冷却。

## 内存与行为正确性

- 取消子女缓存的 32 人硬上限，避免大型家族中后序存活子女被错误排除在继承链之外。
- 伤害战利品分配采用确定性最大余数法，覆盖低总额、平分和极大数值场景，并保证金币总额守恒。
- 继续保留世界切换时的旧世界引用释放、后台任务代际失效和有界历史/事件缓存。
- 修复年度后台任务提交失败后年份被提前消费、任务跨年后快照年份错标、队列拒绝时周期号提前递增的问题。
- 修复战争济贫、革命跨王国分配中的实际扣款、无效接收方、整除余数和大额分块守恒问题。
- 修复银行危机重复计算同一受影响王国、贸易政策在逆差条件下成功但无实际效果的问题。
- 贸易关税按缴费人逐笔结算，城市仓库失败时原缴费人获得退款；财富税和战争济贫先确认接收者再扣款。
- 货币供给与泡沫改为按实际 GDP 基线和实际成功注入金币核算，零 GDP 不再触发零阈值泡沫破裂。
- 王国内再分配恢复全体公民精确计算，并修复 Top-N 候选替换后的边界缓存错误。
- 经济周期和财政政策会对称清除冲突的高/低税率 Trait，避免前期政策永久残留。

## 构建与验证

- 构建系统排除 `tools/` 下的测试与基准源码，发布 DLL 仅包含 39 个生产源文件。
- 构建使用按输出路径隔离的命名互斥锁，支持并发调用并能从异常退出的锁持有者恢复。
- 构建互斥锁按工程根目录统一，多个输出目录仍共享同一诊断文件锁。
- 测试和基准使用独立 GUID 临时目录，运行结束后不遗留可执行文件。
- Roslyn 全量编译、性能审计及 31 个算法/守恒/时间语义/构建稳定性门禁全部通过。

## 已知限制

- 当前 NeoModLoader 的 `IUnloadable` 接口已被标记为无实际效果，因此本版不宣称支持游戏进程内完整卸载模组。
- 长局帧时间、`GC.Alloc` 和跨世界 retained object 仍需在固定存档中使用 Unity Profiler 与 Memory Profiler 复测。
