## 本版本新增：贸易线路 A* 真实路径成本

- **改动前**：非邻国贸易边成本 = 直线欧氏距离（raycast 只判直线可达 + 海洋占比，真实路径直接丢弃）——隔一座山的两个近城按直线计价，且无直线通视的城市对**完全没有贸易边**。
- **改动后**：优先走原版 A* 寻路（`PathfinderTools.tryToGetSimplePath`，EpPathFinding.cs 库，按 ActorAsset 移动规则），**成本 = 真实路径步数**（绕山跨海自然更贵，长度封顶 1024 防畸高）；海陆判定沿用路径海洋占比。
- **连通性只增不减**：A* 失败（API 不可用/无陆行资产/异常）时回退原 raycast 直线逻辑，绝不因 A* 失败丢边；极端长路径封顶后仍计入（非直接丢弃）。
- 新配置 `trade_astar_enabled`（默认开）：关闭则完全回到直线成本。
- 性能：仍受 `trade_max_pathfind_pairs`（默认 100 次/周期）主线程预算约束；A* 内部 2048 步上限。

## 本版本新增：内存数据结构压缩

- **继承记录子嗣缓冲**：`AliveRecord.ChildIds` 从 `List<long>`（24B 对象头 + 容量冗余）改为**定长 `long[]` + `ChildCount`**（初始 2 槽，倍增扩容），省去每个有后嗣记录的对象头与容量浪费；无后嗣记录仍不分配。
- **如实说明**：全库 id 均为 Int64（原版如此，无法变窄），本项压缩收益约 0.1MB 量级——属"能压则压"，模组长驻内存本来就不是大头（此前审计结论）。
- `performance_audit` 对应锚点同步更新为定长缓冲形态（原锚点本意即"记录不得为每个活体分配关系列表"，数组化是同一意图的强化）。
