## 修复：金库收不到钱

**症状**：认领国家后"王室金库：0 金币"，"上期：收入 0｜支出 0"，政策/法令/外交全部因余额不足无法执行。

**根因**：金库的启动资金与每期税负只从**城市仓库**抽金币——而游戏里金币主要躺在**居民（actor.money）口袋**里，城市仓库经常为空，于是国库永远 0。

**修复**（金币全程守恒，都走既有征收管线）：
1. **开国拨款**：认领时除城市仓库 20% 外，新增一次性"开国拨款" = 人口×人均×0.5%（从本国居民征收）。
2. **每期居民税**：税负 = 城市仓库×配置比例 + 人口×人均×0.1%（从居民征收，受原总上限约束）——城市仓库再空，国库也有稳定进项。
