# ClassicalEconomics 性能与内存长期验收清单

## 固定环境

- 固定 WorldBox、NeoModLoader、模组集合、图形设置、时间倍率和存档。
- 对照组为未启用 ClassicalEconomics；实验组使用同一存档和随机种子。
- 每个场景先预热 10 个经济周期，再连续采集至少 100 个周期；每组至少运行 5 次。
- 性能比较使用 5 次运行的中位数。变异系数超过 5% 时延长采样。

## 场景矩阵

| 场景 | 人口 | 城市 | 王国 | 目的 |
|---|---:|---:|---:|---|
| 小型 | 1,000 | 20 | 8 | 行为正确性 |
| 标准 | 5,000 | 80 | 20 | 常规性能 |
| 压力 | 10,000+ | 200+ | 40+ | 年度尖峰和贸易图 |
| 超大长期 | 20,000+ | 400+ | 60+ | GC、缓存和长局内存 |
| 拓扑震荡 | 10,000+ | 持续变化 | 持续变化 | 建城、毁城、建国、灭国 |
| 世界切换 | 任意 | 任意 | 任意 | 主菜单和两个存档往返 20 次 |

## CPU 与 GC

使用 Unity Profiler Development Build 或可用的外部采样器，记录：

- 主线程帧时间 `p50/p95/p99/max`。
- 年份变化帧和经济周期收尾帧耗时。
- `DataCollector.Collect`、`PrepareRoutes`、后台 `Compute`、`ApplyTradeFlows`、`FinishCycle`。
- 每帧及每经济周期 `GC.Alloc`、Gen0/Gen1 次数和 GC 暂停时间。
- 实时刷新关闭和开启两组；人口超过 3,000 时确认只刷新 UI。
- UI 图表持续悬停 60 秒，确认同一数据点内无持续 Tooltip 字符串和布局分配。

通过标准：

- 稳态 `p95` 相对无模组基线恶化不超过 5%，`p99` 不超过 10%。
- 年度主线程尖峰相对优化前版本下降至少 40%，或满足目标帧预算。
- 无年度工作时模组稳态 `GC.Alloc` 接近 0。
- 每周期托管分配相对优化前版本下降至少 50%，且不得较上一发布版增加 10%。

## 贸易不变量

- `_edgeCache.Count` 始终不超过配置 `MaxEdges`。
- 相同存档和配置的稀疏路由边顺序及结果可重复。
- 毁城、灭国或城市换国后，下次拓扑检测不再包含旧边。
- 没有船只的王国海运总额为 0；海运总额不超过 `Boats * 10`。
- 进口城市和居民的实际扣款不小于出口城市实际入库额；日志结算净额不得为正。
- 寻路失败后队列继续推进，不重复卡在同一候选前缀。

## 内存与生命周期

使用 Unity Memory Profiler 在以下时间抓取快照：预热后、运行 500 周期后、返回主菜单 10 秒后、完成 20 次世界切换后。

- 检查旧世界 `Actor`、`City`、`Kingdom` 的 GC Root。
- 静态池不得持有旧世界实体：遗产、时代、危机、叛乱、贸易军力、人口、银行和消费引擎均应为空。
- `DamageTracker` 每个受害者最多保留 16 名主要攻击者。
- Biome 特长和坐标缓存应淘汰已灭亡王国。
- 贸易后台旧代际任务应结束，`_activeWorkers` 最终回到 0。

通过标准：

- 预热后托管堆和进程私有内存线性增长低于 1 MiB/小时。
- 20 次世界切换后 retained memory 增量低于 5 MiB。
- 旧世界 `Actor`、`City`、`Kingdom` retained 数量不随切换次数累积。

## 自动门禁

每次修改后运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\performance_audit.ps1
```

该命令执行完整编译并检查路由边界、近邻算法、伤害记录上限、王国索引、世界引用清理、Tooltip 更新门禁及 Biome 缓存淘汰。它用于阻止静态回归，不能替代真实 WorldBox 长局 Profiler 验证。

配置-文档一致性门禁（修改配置、本地化或 README 后运行）：

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\Test-ConfigDocs.ps1
```

该命令校验全部性能配置键在 `default_config.json`、`UnrestConfig`、`ConfigCallbacks`（AllConfigIds + 有界 ParseInt + 回调）、四种语言 locale（键 + Description）与 README（中/英）中的一致性，fail-closed；同时校验结算标记（`settling_marker` / `settling_hint`）为纯本地化字符串、非配置键。
