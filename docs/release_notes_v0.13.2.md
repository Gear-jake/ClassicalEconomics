# v0.13.2 发布说明（2026-08-19）

## 性能优化

- 将贸易路由从邻国城市全组合改为有硬上限的确定性稀疏图。
- 跨王国城市近邻搜索改为二分定位和固定窗口候选，降低超大地图路由重建开销。
- 王国查询建立周期级 O(1) 索引，减少年度引擎中的重复线性扫描。
- 贸易居民付款和银行危机损失按王国聚合，每个目标王国只扫描一次成员。
- 富人消费缓存年度战争状态，图表 Tooltip 仅在数据点变化时重建布局。

## 内存与稳定性

- 返回主菜单时统一释放遗产、时代、危机、叛乱、人口、银行、贸易军力和消费引擎持有的世界对象。
- 每个受害者最多保留 16 名主要伤害来源，避免长期战争记录无界增长。
- 定期淘汰已灭亡王国的生物群系和首都坐标缓存。
- 修复伤害遗产分配、海运容量和大额金币转换中的溢出及守恒问题。

- Roslyn 全量编译 39 个源文件通过。

- 发布包仅包含运行 DLL、配置、图标、本地化和用户文档。
