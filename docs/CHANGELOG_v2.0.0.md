# 古典经济学 ClassicalEconomics — v2.0.0 更新总览

> 本文档总结 **v1.3.0 之后**（v1.4.0 → v1.8.8，共 46 次提交）进入 v2.0.0 的全部内容。
> v1.3.0 的基线是：删除城市/国家间贸易系统、存档补全、内阁年度刷新、UI 缩放。

---

## v1.4.x — 王国抉择事件（HOI4 式弹窗）

- **v1.4.0**：王国抉择事件系统诞生 + 事件面板重建（16 事件起步）。
- **v1.4.1**：平衡调整——继承比例 80%、经济强盛国民战斗特质、军械打造分档。
- **v1.4.2**：事件库扩到 **56 个**×6 族；**跨年连锁剧情**（借外债→债主上门、王子密谋→余党清算）；**国王名代入**（{king}/{kingdom} 占位符进弹窗文本）；onlyPlayer 宫廷专属事件；三选项两难事件。

## v1.5.x — 银行与商业 / 统治者性格 / 语言跟随

- **v1.5.0 银行与商业**：城市**真实存贷账本**（存款、按利率/额度放贷、到期收本息、违约核销，金币全程守恒）；**央行操作台**（利率/额度/准备金三要素 + 刺激/中性/抑制预设 + 挤兑风险灯）；**真货币政策**——放贷净增计入货币供给驱动通胀与泡沫；市场建筑商业税、特许经营权/低价法案互斥政策。
- **v1.5.1 统治者性格**：读**原版国王性格机制**（贪婪/欺诈/诚实/知足等）——贪婪王侵蚀国库、诚实王主动济贫、政策成功率随性格浮动、议会法典制衡王权。
- **v1.5.2**：修复 AI 银行抽血导致王国崩溃。
- **v1.5.3 / v1.5.4**：界面语言**默认永远跟随游戏本体语言**（彻底移除独立语言设置，修复不切换问题）。

## v1.6.x — 六语言 / UI 精致化 / 78 事件

- **v1.6.0**：**六语言**（简中/繁中/English/Русский/日本語/Deutsch，日文 100% 覆盖、德文 99%）；全界面视觉精致化（石板金边 9-slice、徽章、色带、富事件卡）。
- **v1.6.1**：事件库 **78 个** + 更长的跨年链（3 条三跳链）。
- **v1.6.1fix**：继承比例拉大到 **95%**（同时修复了 1.4.1"80%"只改日志、乘数一直是 0.4 的隐藏回退）。
- **v1.6.2**：UI 布局修复——"王国排名"标题与列头重叠、表头/数据行列宽随缩放对齐。
- **v1.6.3**：移除"本地价"列——顺带发现并清理了从未被真正计算的死代码链（LocalPrice 恒为 0）。

## v1.7.x — 318 事件 + 每局随机化

- **v1.7.0（重磅）**：事件库 **78 → 318**（财政 56 / 宫廷 55 / 军事 54 / 天灾 51 / 民生 51 / 外交 51），18 条跨年链；**三大每局随机化机制**：
  - **种子事件池**：按世界种子（读档同局不变）确定性启用约 68% 事件，链/变体组整体启用绝不断链；
  - **变体互斥组 ×12**：同剧情多种版本每局只出部分（这局蝗灾、那局洪水）；
  - **族倾向轮换**：每局六族权重 0.65~1.4（天灾之局 / 宫廷之局 / 战乱之局）。
  - 同时修复历史 bug：14 个事件的嵌套 `conditions` 被 Newtonsoft **静默忽略从未生效**，全部转平。
- **v1.7.1 / v1.7.2**：兴建原版建筑清单修正——神庙（不可用）→**大厅**，新增**风车**（均按种族自动匹配）。
- **v1.7.3**：**只剩一座城的王国不再触发起义**（避免灭国级政权崩塌）。
- **v1.7.4**：**事件流随存档持久化**——保存/自动保存后重新打开存档，历史 GDP 图、事件时间线、类型统计全部恢复显示。

## v1.8.x — 效果库扩展 / 事件可达性

- **v1.8.0（重磅）**：**效果库扩展**——抉择事件选项新增六类效果：
  - **宣战**（对最强/最弱/随机/当前交战国，AI 国也主动宣战）
  - **结盟**（关系最好/最强/随机国）
  - **迁都**（迁第二大城市）
  - **建筑升级**（城市可升级建筑升 N 座）
  - **个体发财/破产**（富豪暴富 / 民众破产，直连 GDP 与基尼）
  - **世界大战**（原版 total-war：全世界围攻事件国，稀有度 rarityWeight=0.08，约 1/12 概率）
  - 事件库 318 → **330**（新增 12 事件：世界大战 ×2、宣战 ×3、结盟 ×3、迁都 ×2、营造 ×1、巨贾 ×1），六语全量文案。
- **v1.8.1**：22 个既有事件按语义接入新效果（23 处选项：联姻→结盟、战争升级→宣战、火山/地裂→迁都、堡垒/灯火→建筑升级、投机/剪币→发财/破产）。
- **v1.8.2**：抉择小窗**倒计时逐年递减**（修复跨年不刷新）。
- **v1.8.3 ~ v1.8.8**：国家/城市窗口账本入口按钮定位反复调整后，最终改为**可拖动**——按住拖到任意位置，松手即记住（会话内），此后所有窗口按你的位置注入；拖拽与点击不冲突。
