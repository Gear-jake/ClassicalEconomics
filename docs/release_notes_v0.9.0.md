# v0.9.0 发布说明（2026-08-13）

## 地理贸易增强

贸易从"无空间维度的抽象金流"升级为真实的地理经济。三组新机制 + 面板升级 + 界面修复：

### 地理距离衰减
- 后台线程解析各王国首都城市 tile 坐标（多候选字段名动态探测 + 缓存，零性能开销）
- 贸易额按 `1/(1+平均距离×距离衰减系数)` 衰减：相距遥远的王国贸易变弱，经济更地方化
- 坐标未知的王国回退因子 1（不惩罚），王国建城后自动生效

### 运输成本
- 贸易固定摩擦，按比例吃掉全部贸易额
- 物流成本越重，总贸易越少

### 区域价格与套利贸易
- 各王国按本地供需形成区域价格指数：
  - 供给侧：人均产出高 → 供给充足 → 本地价低
  - 需求侧：人口超载 → 需求旺盛 → 本地价高
- 本地价低于均价者出口盈余、高于者进口逆差
- 价格差权重驱动套利金流

### 面板新增
- 指标卡"价格离散"：区域价格变异系数 CV（0=各地同价，反映区域套利空间）
- 王国排行新增"本地价"列：≥1.3× 基准通胀琥珀 / ≤0.8× 廉价信息蓝

### 界面修复
- 指标卡网格改为多行布局：卡片超过 3 个不再横向溢出

### 新增配置（四语言本地化）
| 配置 | 范围 | 默认 | 说明 |
|------|------|------|------|
| 距离衰减系数 | 0~0.05 | 0.005 | 贸易额随距离按 1/(1+平均距离×系数) 衰减 |
| 运输成本 | 0~0.3 | 0.05 | 贸易固定摩擦，按比例吃掉贸易额 |
| 价格差权重 | 0~1 | 0.3 | 区域价格差异对贸易额的加成权重 |

## 性能
- 全部新增计算在后台线程完成（O(m²) 距离矩阵仅 m=王国数，可忽略）
- 坐标反射按 tile 类型解析一次并缓存 FieldInfo，首都坐标按王国缓存
