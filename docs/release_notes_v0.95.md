## 新玩法：中央银行家

1. **认领国家（原版界面入口）**：点击地图上的国家/城市，**原版国家/城市窗口内**会出现账本图标按钮（窗口右上角，PowerBox/XaviiNationTypes 同款注入方式：Harmony 补丁 StatsWindow.create + NML PowerButtonCreator）——点击即认领该国并打开内阁面板；已认领国家点击直接进入内阁。单国制，切换 10 年冷却，国家灭亡自动解绑。
2. **王室财政**：认领时从该国城市仓库转入 20% 金币作启动资金；每期自动征收税负（比例可配，默认 5%）；所有动作真实扣费，余额不足则禁用/暂停。金币全程守恒。
3. **持续政策**（槽位默认 3 个，三档 少/中/大）：减税刺激、加税充实、济贫院、宣传、贸易协定、关税——全部挂钩现有引擎（税率特质/济贫分配/动荡暂停/贸易流量乘数/物价乘数），有真实副作用（加税升基尼、关税降贸易量等）。
4. **一次性法令**：紧急救济（最穷 20% 国民，5 年冷却）、国庆庆典（清除动荡 + 红包，3 年冷却）、兴建建筑。
5. **世界建筑**：市场（贸易容量 +20%）、粮仓（灾害财富蒸发 ×0.7）——可被战争掠夺与灾害摧毁，无赔偿。
6. **政绩记录**：内阁面板记录每笔政策/法令的年份、金额与执行前后基尼/人均对比，形成"我做了什么 → 世界变了什么"的闭环。
