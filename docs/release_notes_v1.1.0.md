# v1.1.0 发布说明（可安装候选包已生成）

> 状态说明：内阁面板重构为 RulerBox 式「枢纽-页面」布局；45/45 门禁 + performance_audit + 构建全绿。

## 页面重构：财政 / 政策 / 法令·建设 / 外交

学习 RulerBox 的页面设计后，把内阁从"单页小窗塞全功能"重构为**四页 Tab 切换**（顶部 Tab 栏，打开即切换，选中高亮）：

- **窗口放大**：400×640 → **600×760**，每页获得整幅内容宽度。
- **财税页**：本国信息 + 王室金库 + 上期收支 + 切换冷却 + 政绩记录（前后指标对比）。
- **政策页**：6 个持续政策（减税/加税/济贫/宣传/协定/关税），每项独立三档按钮 + 年费明细，槽位 N/M 与提示行。
- **法令·建设页**：紧急救济 / 国庆庆典 + 城市建筑列表（市场/粮仓，前 12 城）。
- **外交页**：他国列表（GDP 前 12）每国一行：原版好感 + 赠礼好感 + 协定档位 + 宣战/求和/结盟/协定/赠礼 5 个按钮；整页可滚动。
- 未认领时任意页顶部显示国家认领列表（认领后自动回到该页继续操作）。

页面切换只重建当前页（其余页保持隐藏，零开销）；Tab 与页面标题四语言（新增 7 键 × 4 语言）。
