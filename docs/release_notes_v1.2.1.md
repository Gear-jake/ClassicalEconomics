# v1.2.1 发布说明（可安装候选包已生成）

> 状态说明：code-review（Standards × Spec 双轴）发现的全部问题修复——含 2 个阻断级 bug、2 个性能热点、5 个 spec 缺口；46/46 门禁 + performance_audit（49 源文件）+ 构建全绿。

## 阻断级修复（v1.2.0 用户必升）

1. **AI 演变从未执行**：RunAnnual 先写 `LastEvalYear` 再调 TickNation，而 TickNation 首行用同值防重入 → 全王国 AI 从不自动变法。已调整顺序（先决策后写年份）。
2. **后台线程数据竞争**：贸易后台线程直接读 LawEngine 共享字典（每周期约 1.6 万次查询 + 非原子 struct 存取），与主线程年度写并发。已改为**采集时快照**——主线程把各国聚合乘数拷入 KingdomFacts（纯数据快照），后台线程只读快照，彻底消除跨线程访问；后台热路径零字典查询。

## 性能优化（本版本重点）

3. **年度评估开销**：原每条法律调 `IsAtWarWith`（每次分配战争列表 + 反射）28 次/国/年；已 hoist 为一年判定一次；`CollectAIFunds` 的 `new List<Actor>` 改为静态复用池。
4. **事件分级正确性**：军事法律"重大变法"原按最终态判定（年年刷屏）；改为只统计本 tick 实际变更。
5. **并发数据快照**：生产/价格/贸易流量 3 处后台读取全改为快照（见 #2）。

## Spec 缺口补齐

6. **5 年互斥冷却**（原字段死代码）：AI 做互斥切换后冷却 5 年，防反复振荡。
7. **AI 建议+一键采纳**：法典页顶部（玩家国）显示 3 条国情建议，一键采纳。
8. **外交页显示国性**：他国行下加"国性：XX"。
9. **互斥清零前先付款**：原实现先清互斥再检查支付，付款失败时互斥对已死（双 0 状态）；已改为付费成功后才清互斥。
10. **Style=0 哨兵碰撞**：尚武好战（风格 0）王国每年被误判为"未掷"重掷风格；改 -1 哨兵。

## 其他

- 玩家改法不再写入外交事件流（避免污染）；贸易军力修正由"硬顶档位"改为**阈值换算**（军国降门槛、和平抬门槛，保留原顺逆差阈值语义）；死代码与命名清理（BuildPolicyRow2 → BuildLawPolicyRow、教育分支恒假判断删、LawMods 提升为命名空间级结构体）。
- Test-LawLaws 计数断言改为按 law_*/policy_* 字面量计数（原正则受数组换行形态影响失效）。
