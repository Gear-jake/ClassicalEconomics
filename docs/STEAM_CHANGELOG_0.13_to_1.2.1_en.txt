[h1]Classical Economics — Full Changelog v0.13.0 → v1.2.1[/h1]
[b]WorldBox macroeconomic simulation mod | Current version 1.2.1 | Requires NeoModLoader (NML)[/b]

Since 0.13.0 the mod has grown from an "economic statistics" layer into a full national-governance simulation: performance governance, playable government (Central Banker), diplomacy and a national law codex that every AI kingdom evolves on its own — with every effect genuinely wired to the engine and a complete four-language UI. Per-version changelog below.

[h2]Performance & stability foundation (0.13.x)[/h2]
[list]
[*]v0.13.1 Memory lifecycle: releases static cache references on world switch / main menu; trade-edge cache evicts dead cities/kingdoms; compute buffers locked until background task fully exits; hot-reload no longer duplicates ticker/UI
[*]v0.13.2 Performance: deterministic sparse trade graph (hard cap); binary-locator near-neighbor search; O(1) kingdom index; per-kingdom aggregated payments
[*]v0.13.9 Performance: shared inheritance/damage scan (population-level hash writes halved); exact lower-bound pruning for nearest neighbors; unified cycle-based cooldown eviction
[/list]

[h2]v1.2.0 National law codex[/h2]
[list]

[h2]v1.2.1 Code-review fixes[/h2]
[list]
[*]Critical: AI evolution never ran (year guard set before the tick call) — reordered
[*]Critical: background thread raced the shared dictionary — snapshots taken at collect time (≈16 k lookups per cycle eliminated)
[*]Event tiering fixed (major reforms only from this-tick changes); player edits no longer pollute the diplomacy stream; military balancing via threshold scaling
[*]Spec gaps filled: 5-year mutex cooldown, one-click adopt of AI suggestions, national nature shown in diplomacy rows
[/list]

[b]Note:[/b] Built entirely on vanilla mechanics, no external assets; four-language UI (Simplified/Traditional Chinese, English, Russian).
