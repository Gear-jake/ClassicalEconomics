# ClassicalEconomics v2.1.0 开发计划：综合性能优化（测量先行）

> 定稿日期：2026-09-08。基于 v2.0.0 全量性能审理（5 路并行审计 + 门禁清单盘点）。
> 前置：`build_local.ps1` exit 0（`BUILD_OK: bin\EconomyMod.dll 346112 bytes`）、`performance_audit.ps1` exit 0（`PERFORMANCE_AUDIT_OK: 108 source files`）为已验证起点。
> 核心决策：**先补测量，再动代码**；**零新增配置项**；**不动 BankingEngine.cs**。

---

## 0. 设计总纲

**一句话：把每年 6–8 次全量 actor 扫描收敛为 1 次，把每秒/每年的主线程重算挪出主线程，把 UI 的销毁重建换成池化复用——全程在现有门禁下做行为等价改造。**

三条铁律：

1. **测量先行**：v2.0.0 当前**无法证明任何优化变快了**（无逐帧 profiler、无分配热点归因、无吞吐基准、内存基线停留在 2026-08-19 且早于 v2.0.0）。S1 不产出性能收益，只产出"可验收"这件事本身。
2. **行为等价优先于性能**：所有缓存/融合改造必须能通过黄金行为一致性哈希（金钱总量精确匹配）。无法证明等价的改造不做。
3. **门禁即约束**：门禁是**正则锚定的静态源码扫描**，重构会直接打断它。必须使用预分配静态缓冲或池租用——**池化在本项目不是可选项，是必选项**。

### 0.2 硬约束清单（违反即门禁 RED）

**分配禁令区**（`new\s+(List|Dictionary)<` 在这些区内非法 → 只能用静态缓冲/池租用）：

| 文件 | 区域锚点 |
|---|---|
| `Core\DataCollector.cs` | `public static void ApplyWealthTax(` → `private static void UpdateTopRich(` |
| `Core\SpendingEngine.cs` | `public static void RunOncePerYear(` → `public static void ClearWorldReferences(` |
| `Core\BankingEngine.cs` | `public static void Evaluate(` → 文件尾（**本方案完全不碰此文件**） |
| `Core\TradeSimulationWorker.cs` | `private static CycleResult Compute(` → `private static float ComputeGini(` |

**GC 禁令**：`GCSettings` 全产品源绝对禁止；`GC.Collect` 仅允许出现在 `Core\MemoryCleanupEngine.cs` 中同时引用 `MemoryCleanupForceGc` 的那一行。

**必须逐字保留**（正则锚定）：

- `EconomyModMain.cs` 注释标记：`consumption(spending) -> banking -> other`、`over-budget fallback reduction order: spending caps -> banking caps -> other stages`、`the wealth-tax/redistribution path is never reduced (tax conservation)`
- 字段名：`_pendingYear` / `_lastCollectedYear` / `_cyclePending`
- 区域锚点方法签名（见上表）
- 常量：`MaxAttackersPerVictim = 16`、`MaxInactiveScans = 10`、`BuildCooldownCycles = 50`、`WeakTierPrice = 30` / `MidTierPrice = 80` / `StrongTierPrice = 200`、`PoolRetainRatio = 0.68f`、`FamilyBiasMin = 0.65f`、`FamilyBiasMax = 1.4f`、`HardWindowMs = 5000L`、`FrameBudgetMs = 4`、`CycleAllocBudget = 4096`、`CycleWindowMs = 2000`

**守恒不变量**：金币不生不灭；**先确认接收者再扣款**；整数余数归首位接收者；超预算削减顺序 consumption→banking→other，**税收/再分配路径永不削减**。

**配置五向一致**：新增 1 个配置键要改 5 处（default_config.json / UnrestConfig.cs / ConfigCallbacks.cs+AllConfigIds / 4 语 locale / 两份 README）。**本方案硬性规定：零新增配置项。**

**Unity 线程规则**：`DataCollector.Collect` 触碰 Actor/Kingdom 等 Unity 对象，**只能主线程**；可异步的只有 `TradeSimulationWorker.Compute`（纯数值）。
