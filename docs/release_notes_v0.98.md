## 外交（经济+外交大臣，实时生效）

内阁面板新增"外交"区块：列出其他国家（按 GDP 前 8），每国一行显示**原版好感 + 赠礼好感 + 协定档位**，五个动作按钮全部实时生效：

1. **宣战**：以本国名义向目标国宣战（原版 `DiplomacyManager.startWar`，战争类型 whisper_of_war）；共同联盟因背叛自动瓦解。
2. **求和**：我方军力 ≥ 对方 → 免费和谈；军力弱于对方 → 按军力差支付赎金（金库，封顶 5000 金币），余额不足无法求和。
3. **结盟**：无战争 +（原版好感 + 赠礼好感）≥ 0 才可结盟；双方均无联盟 → 新建，单方有 → 加入（原版 `AllianceManager`）。
4. **外交赠礼**：金库支付 500 金币真实转移给目标国国民（守恒），累计"赠礼好感"（上限 200）——结盟门槛的一部分，花钱买外交。
5. **双边贸易协定**：与指定国家签协定（三档 少/中/大 = 每档 +10% 双边边流量），槽位上限 2；年费 = GDP×0.3%×档（金库不足自动解除）；同国升档/取消即时生效。

全部经原版外交 API 反射调用（与 RulerBox 同源接口），任一接口不可用时 fail-closed 并横幅提示；动作记录进事件流。
