# v1.0.0 发布说明（可安装候选包已生成）

> 状态说明：从 v0.91 起的全部治理与玩法特性在 1.0.0 汇合——性能治理（年度分帧/诊断/内存清理）、玩家参与度（中央银行家：认领国家/王室金库/政策/法令/世界建筑）、外交（宣战/求和/结盟/双边协定/赠礼）、大地图快捷键（默认 G 可改）、A* 真实贸易成本、全面本地化；45/45 门禁 + performance_audit（46 源文件）+ 构建全绿。F3 实机验收由用户安装到游戏后亲自执行。

## 本版本新增

1. **大地图快捷键 G**（可配置，`nation_claim_hotkey`）：鼠标悬停国家按 G —— 未认领则自动认领并打开内阁面板，已认领直接打开。（原默认 C 现改 G；任意 Unity KeyCode 名可填，留空禁用。）
2. **政绩记录 bug 修复**：`nation_claim` 记录名缺少四语言翻译（曾在面板显示英文键名），已补全部语言；认领记录的金额原写死 0，现改为显示实际转入金库的启动资金。
3. **全面本地化收口**：四语言键集合一致性强校验（Test-LocalizationCoverage 现在断言 ch/zh_tw/en/ru 键集完全相同——任一语言缺键即 RED），全部新增键四语言齐全，共 448 键 × 4 语言。

## 1.0.0 特性全览（v0.91 → v1.0.0 累积）

- **性能治理（v0.91）**：年度收尾分帧状态机（单帧 4ms 预算/2 秒窗口/兜底削减顺序 消费→银行→其他、税收永不削减）、PerfDiagnostics 年度诊断、继承扫描分片、动态分配清理、RealTimeRefresh 熔断。
- **自动内存清理（v0.92→）**：空闲期 List 缩容 + 14 个静态字典重建缩容 + 三通道结果（横幅/HUD 内存状态行/日志）；清理提示与释放量；忙碌 5 秒重试。
- **本地化修复（v0.93）**：四个悬浮窗标题切语言即时刷新；18 处顶部横幅本地化；指标卡/事件流描述/工具栏 tooltip 全部收口到四语言 JSON。
- **玩家参与度·中央银行家（v0.95）**：认领国家（单国制/10 年切换冷却）、王室金库（城市仓库 20% 启动资金/每期税负）、6 个持续政策 × 三档槽位制、3 个一次性法令、市场/粮仓世界建筑（可被战争与灾害摧毁）、政绩记录（前后指标对比）、**原版国家/城市窗口入口按钮**。
- **外交（v0.98）**：宣战/求和（军力差赎金）/结盟/外交赠礼/双边贸易协定（槽位 2），实时生效，走原版 DiplomacyManager/WarManager/AllianceManager。
- **贸易 A* 真实路径成本（v0.96）**：非邻国边成本改用原版 A* 真实路径步数（默认开，可关），海陆判定不变，A* 失败回退直线（连通性只增不减）。
- **快捷键（v0.99→）**：大地图按键打开内阁（默认 G，可配置）。

## 兼容与验证

- 45/45 门禁 + performance_audit（46 源文件）+ 构建全绿；DLL 哈希包内一致（见打包记录）。
