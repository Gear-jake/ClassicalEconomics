# 古典经济学 ClassicalEconomics —— Q 群模组介绍（v2.0.0）

> 一句话：**给 WorldBox 装上真实的经济系统，让你扮演一个国家的中央银行家，看 AI 各国自己治国、打仗、崩溃、复兴。**

---

## 这是什么模组？

原版 WorldBox 里，王国只是个会打仗的盒子。装了这个模组之后：

- **每个文明种族都有钱**。财富按人头采集，算出 GDP、人均、基尼系数、CPI，拆到每个王国。
- **经济会生病**。繁荣→衰退→萧条→复苏四个阶段轮转，泡沫会破裂，饥荒会来，通胀会把你的金库吃空。
- **你能当中央银行家**。地图上悬停一个国家按 **G** 认领它，王室金库、税负、政策、法令、建筑、外交全归你管。

## 最值得玩的三件事

### 1. 开银行，玩真的货币
城市银行有**真实账本**：居民存钱、你按利率放贷、到期收本息、坏账核销——每一枚金币都守恒。央行操作台三要素（利率/额度/准备金）能调出通胀、挤兑和泡沫。调错一次，王国说崩就崩。

### 2. 每个国家都有 28 部法律 × 16 项国策
**AI 国家也会自己变法**——按国情和六种国性（尚武/重商/仁政/法理/闭关/科技）自动演变。效果真实生效：征兵法涨军力、专卖法抽盐税、教育法给国民加生育。你自己认领的国家也一样，升档要花钱，降档免费。

### 3. 330 个抉择事件，每一局都不一样
财政、天灾、宫廷、军事、民生、外交六个族，事件会弹窗让你拍板（HOI4 风格）：借不借外债、杀不杀贪官、宣不宣战。关键是——

- **每局随机**：按世界种子启用约 68% 事件，这局有的剧情下局没有；
- **变体互斥**：同一条剧情有多种版本，这局是蝗灾，那局是洪水；
- **族倾向**：一局天灾频仍、一局宫廷喧哗、一局战火连天；
- **连锁剧情**：借了外债，两年后债主真会找上门；王子密谋败露，余党还会清算；
- **事件效果是真的**：选项可以**宣战、结盟、迁都、升级建筑、让富豪暴富或破产，甚至触发世界大战**（概率极小，全世界打你一个）。

## v2.0.0 都更新了什么？

从 1.3.0 到现在，几乎重做了一遍模组：

| 系统 | 内容 |
|---|---|
| 抉择事件 | 56 → 78 → **330 个**，六族全扩，18 条跨年连锁 |
| 每局随机化 | 世界种子事件池 + 12 组变体互斥 + 族倾向轮换（全新） |
| 事件效果库 | 宣战/结盟/迁都/建筑升级/个体发财破产/世界大战（全新） |
| 银行与商业 | 真实存贷账本、央行操作台、货币政策、挤兑风险 |
| 统治者性格 | 读原版国王性格：贪婪王贪国库、诚实王济贫 |
| 法典 | 28 法 ×5 档 + 16 国策 ×3 档，AI 自动演变，国民特质可见 |
| 语言 | **六语言**，默认跟随游戏本体语言 |
| UI | 石板金边 9-slice、字体按钮 0.8~1.6 倍缩放、账本按钮可拖动 |
| 存档 | 金库/政策/法典/事件流/历史图全部随存档保存，读档恢复 |
| 平衡 | 单城不起义、继承 95%、AI 银行不再抽血 |

## 安装（两分钟）

1. 装 **NeoModLoader（NML）**——WorldBox 的模组加载器；
2. 把 `EconomyMod` 文件夹整个放进 `WorldBox/Mods/`；
3. 进游戏 → 模组菜单 → 启用「古典经济学」。

旧存档直接读，不用开新档。

## 操作速查

| 按键/位置 | 功能 |
|---|---|
| 悬停国家按 **G** | 认领国家 / 打开内阁（设置页可改键） |
| 国家/城市窗口右上角**账本按钮** | 打开内阁（**可以按住拖动**到任意位置） |
| 内阁五个 Tab | 财税 / 政策 / 法令·建设 / 外交 / 法典 |
| 建设页 | 选房屋/兵营/瞭望塔/大厅/风车等 11 种原版建筑，点地图放置 |

## 常见问题

- **语言不对？** 模组默认跟随游戏本体语言，不用单独设置；想固定可在设置页手动选。
- **认领不了国家？** 先确认打开了 Nation Play（设置页），再悬停国家按 G。
- **AI 国家会自己玩吗？** 会。法典自己变、事件自己决策（按国性）、战争自己打，你不管它它照样热闹。
- **和其他模组冲突吗？** 基于原版机制，和 Optime 等优化模组兼容；所有数据走原版存档键。
