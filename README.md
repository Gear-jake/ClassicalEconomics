> 为 WorldBox 引入完整的宏观经济模拟 —— 财富采集、经济周期、王国贸易、社会动荡与智慧生物消费。

## 模组简介

"古典经济学"让你的世界真正拥有经济。模组会识别所有**智慧生物**（包括外星人、龙等能建立文明的种族）的财富，并以此为基础模拟一整套宏观经济运行：

- 每年自动采集所有开智种族的金币与战利品，计算**全球 GDP、人均财富、基尼系数、物价指数**
- 财富会驱动 **繁荣 → 衰退 → 萧条 → 复苏** 的完整经济周期
- 王国之间通过**贸易金流**重新分配财富（不凭空造币），并按**生物群系经济特长**形成比较优势贸易
- 贫富差距会引发**动荡、叛乱、革命**，也会触发国王**加税、改革**
- 富裕的智慧生物每年大量消费：买武器、建投资、造军械、缴税、施舍穷人……
- 生物死亡时财富按 **父母 → 配偶 → 子嗣** 顺序继承，城市村长收取遗产税
- **劳动分工**：职业人口每年靠劳动创造工资（生产函数）
- **银行信贷**：富人放贷给穷人，萧条期违约率飙升，危机沿贸易路线传染
- **灾害冲击**：火山、陨石等灾害蒸发受灾城市财富，火山短期提振矿产
- 支持 **简中 / 繁中 / English / Русский** 四语言界面一键切换
一切以**游戏原版机制**为基础，不引入任何外部资源，数据全程在后台线程计算。
## 核心功能

### 1. 宏观经济统计
- 采集**所有智慧种族**的财富（按种族智慧特质判定，外星人当国王也能统计）
- 全球总财富（GDP）、人均财富、文明人口
- **基尼系数**：0 = 完全均等，1 = 完全不均等
- **物价指数（CPI）**：随货币流通速度与泡沫升温而上涨，直观呈现通胀
- 按王国拆分：各王国财富、人均、贫富差距、人口

### 2. 经济周期
- 四阶段周期：**繁荣 → 衰退 → 萧条 → 复苏**，阶段转移由全球贫富差距驱动
- 繁荣期：信用扩张，按 GDP 比例注入金币，泡沫持续累积
- 泡沫破裂：累积泡沫超过阈值，大量金币蒸发，转入衰退
- 萧条期：人均财富跌破生存线 → 饥荒，贫困人口死亡
- 复苏期：缓慢回暖，重建信心
- 可在工具栏手动切换经济阶段

### 3. 社会动荡与革命
- 自动检测贫富差距大的王国，触发原版叛乱
- **煽动动荡 / 镇压动乱**：选择任意王国手动干预
- 叛乱持续过久 → 革命爆发：旧政权被推翻，王国人口按比例死亡
- 战争掠夺：战争结束后胜方掠夺败方金币

### 4. 王国贸易金流
- 人均财富高于全球均值的王国为贸易**顺差**（获得金币），低于者为**逆差**（支付金币）
- 金币经城市仓库结算，与原版缴税同渠道
- 全王国顺差总额 = 逆差总额，**总和为零，不凭空造币**

### 5. 生物群系经济特长
- 每个王国按领地特征获得一种**产出特长**（农业/狩猎/伐木/采矿/建造……），有对应的产出加成
- 特长王国为贸易**出口**方，非特长王国为**进口**方，驱动**比较优势贸易**
- 特产加成与王国实际领地动态匹配，形成天然的分工格局

### 6. 劳动分工（生产函数）
- 读取原生 `citizen_job` 职业，按职业挂钩财富生产率
- 职业人口每年靠劳动创造"工资"（劳动创造财富），无业人口生产率低、不创造工资
- 职业 → 代码映射与生产率表均为纯数据，由后台线程聚合每王国劳动统计

### 7. 智慧生物消费系统
富人不再囤积金币——每年按财富比例消费，**七种消费方式**轮换：

| 消费方式 | 说明 |
|---------|------|
| 购买武器 | 富人为自己购置真实武器 |
| 建造投资 | 投资建造防御塔楼 |
| 制造军械 | 大量制造装备和武器 |
| 武器批发 | 整批采购武器 |
| 时代事件 | 花费金币触发时代事件 |
| 慈善施舍 | 金币转移给同城最穷的智慧生物 |
| 缴纳税收 | 金币缴纳给城市仓库 |

金币**不会凭空消失**——全部真实流向城市领袖、穷人或国家财政。

### 8. 王国时代事件
- **盛世**：国民幸福 +30、生育 +10
- **复兴**：国民幸福 +35、伤害 +10、生育 +10
- **强盛期**：国民幸福 +20、伤害 +5、护甲 +5
- **经济崩溃**：萧条期 + 人均财富大幅下滑触发，国民幸福 -15、伤害 +30、护甲 +20，并伴随人口流失

### 9. 银行信贷与危机传染
- 富人（财富 > 2×人均）自动放贷给同城穷人，按年利率计息
- 萧条期**违约率飙升**，违约直接造成放贷人（富人）财富损失
- 违约率越过阈值触发**银行危机**，沿贸易路线传染逆差贸易伙伴（危机传染）
- 统计级模拟（不存储个债记录），零内存膨胀

### 10. 灾害经济冲击
- 检测三类灾害信号：王国人口骤降 >30%、城市数骤降 >25%、城市 tile 为灾害类型（火山/陨石坑）
- 受灾城市仓库财富按比例**蒸发**（财富真实消失）
- 火山短期提振矿产：繁荣期受灾区域产出获得额外加成
- 效果检测 + tile 反射检测，无需 hook 原版灾害事件，兼容所有灾害类型

### 11. 遗产继承
- 智慧生物死亡时，金币按 **父母 → 配偶 → 子嗣** 顺序转移
- 城市（村长）收取遗产税
- 无任何继承者时，全部财产归村长所有

### 12. 政策与治理
- 高基尼系数的王国会尝试推行**贫富调节政策**
- 政策失败则统治者退位（甚至死亡）——经济治理失败是要付出代价的

### 13. 人口与劳动力
- 人口压力：王国人口 vs 承载力
- 劳动生产率：按职业统计产出

## 界面功能

底部工具栏新增**经济 Tab**（金币图标），包含 7 个按钮（鼠标悬停可查看提示）：

| 按钮 | 功能 |
|------|------|
| 经济概览 | 打开/关闭经济主面板（可拖拽、可缩放、不暂停游戏） |
| 干预王国 | 选择王国进行煽动或镇压 |
| 立即采集 | 手动执行一次数据采集与经济重算 |
| 清除历史 | 清空所有历史快照数据 |
| 全球富豪榜 | 查看财富排行 |
| 经济事件 | 打开/关闭事件流悬浮窗 |
| 切换阶段 | 循环切换经济阶段（繁荣→衰退→萧条→复苏） |

**经济概览面板**包含：
- 概览页：GDP、人均、人口、贫富差距、王国排名
- 趋势页：**财富趋势图**（全球财富 + 动态 Top5 王国折线 + 阶段色带 + 竖行图例 + 宏观指标摘要）+ **贫富差距趋势图**
- 社会震荡状态、历史快照

**趋势图特性**（v0.7.0 重制）：
- **动态国家折线**：国家进榜后折线出现、跌出排名后折线断裂消失、再入榜自动续线
- **阶段色带背景**：绿繁荣 / 橙衰退 / 红萧条 / 蓝复苏，一目了然的经济周期轨迹
- **宏观指标摘要**：总产出、物价指数、文明人口、人均财富、贫富差距一行概览
- **竖行图例**：逐行显示国家色块、名称与最新值；跌出榜的国家以灰色标注"已跌出"

支持 **简中 / 繁中 / English / Русский** 四语言界面一键切换（随游戏语言自动切换，也可在设置中固定界面语言）。

## 配置项（模组设置）

所有参数均可通过 NML 模组设置界面调整，包括：
- **界面语言**：ui_language（简中/繁中/英文/俄文，独立于游戏语言）

- 生存线、饥荒死亡率
- 战争掠夺比例、战争浪费比例、革命触发延迟、革命击杀比例
- 街头起义阈值、起义延迟、处决富豪比例、劫富济贫再分配比例
- 财产税开关、税率、免征线
- 贸易开关、贸易流量比例
- 劳动分工开关、基础工资
- 时代事件开关、持续时间、经济崩溃比例
- 实时数据刷新开关与间隔
- 银行信贷开关、年利率、萧条违约率、危机传染阈值
- 灾害冲击开关、财富蒸发比例、火山矿产加成
- 货币流通速度、泡沫期通胀加成
- 世界日志输出开关

## 安装方法
手动安装
1. 将 `EconomyMod` 文件夹放入 `WorldBox/Mods/` 目录
2. 确认目录结构为：
   ```
   WorldBox/
   └── Mods/
       └── EconomyMod/
           ├── EconomyMod.dll
           ├── mod.json
           ├── icon.png
           └── Locales/
               ├── ch.json
               ├── zh_tw.json
               ├── en.json
               └── ru.json
   ```
3. 启动游戏，在模组列表中启用"古典经济学"

### 依赖
- 需要安装 **NeoModLoader (NML)** 模组加载器
- 建议使用最新版 WorldBox

## 常见问题
**Q：经济会一直卡在复苏吗？**
不会。可以点击工具栏的"切换阶段"按钮循环手动切换阶段（繁荣→衰退→萧条→复苏）。
**Q：会影响游戏性能吗？**
不会。统计计算全部在后台线程完成，主线程只做采集与显示。
