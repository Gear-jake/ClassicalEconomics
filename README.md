# 古典经济学 Classical Economics

> WorldBox 宏观经济 + 国家治理模拟模组 ｜ 当前版本 *1.2.1fix* ｜ 需要 NeoModLoader (NML)

## 功能总览

**宏观经济学**
- 全种族（含恶魔/外星人）财富采集：GDP / 人均 / 基尼系数 / CPI，按王国拆分
- 经济周期：繁荣 → 衰退 → 萧条 → 复苏，泡沫破裂、饥荒、货币供给与通胀
- 地理贸易：A* 真实路径成本（绕山跨海）、海路惩罚、生物群系比较优势、贸易净额排名
- 劳动分工工资、银行信贷与违约传染、灾害经济冲击、遗产继承 / 伤害追凶分配
- 社会动荡：叛乱 → 起义 → 革命，战争掠夺与王位继承监测

**玩家扮演 · 中央银行家**
- 大地图悬停国家按 **G**（设置页可改键）：认领国家 / 打开内阁
- 王室金库：认领拨款 + 每期税负（居民税 + 仓库税），政策/法令/建筑/外交全部真实扣费
- 6 个持续政策 × 三档槽位制、一次性法令（救济/庆典）、**原版建筑放置**（房屋/兵营/瞭望塔/水井等 10 种，点击地图建造）
- 政绩记录 + 本国 GDP 趋势图（近 40 期）
- 外交：宣战 / 求和（军力差赎金）/ 结盟 / 赠礼 / 双边贸易协定——RulerBox 式两级页面（列表 → 详情：三层旗章 + 国家数据）

**国法体系 · 法典**
- **全王国（AI 各国）法律 28 条 × 5 档 + 国策 16 条 × 3 档**，每年按国情自动演变（财政/基尼/战争/人口/灾害 + 6 种国性）
- 互斥法组合、升档付费降档免费；效果真实挂接 10 个引擎（生产/贸易/物价/基尼/动荡/消费/灾害/建筑费/工资/军力）
- 法典加成落到**国民特质**（教育之国/武备之国等，幸福/伤害/护甲/生育可见加成）；法典写入存档
- 法典页实时聚合效果总览 + 档位语义名（如 贸易自由：无贸易保护 → 闭关锁国）

**性能与质量**
- 年度结算分帧（4ms/帧，超时削减仅限消费/银行，**税收永不削减**）、自动内存清理
- 46 项自动化门禁 + 性能审计；全部金币转移守恒
- 四语言界面（简体 / 繁體 / English / Русский）；石板金边 9-slice UI

## 安装

1. 安装 [NeoModLoader](https://github.com/neoModLoader) (NML)
2. 将 `EconomyMod` 文件夹放入 `WorldBox/Mods/`
3. 游戏内模组列表启用「古典经济学」

## 操作提示

- **G**（可改键）：大地图悬停国家 → 认领 / 打开内阁（也可点国家窗口右上角账本按钮）
- 内阁 5 页：财税 / 政策 / 法令·建设 / 外交 / 法典
